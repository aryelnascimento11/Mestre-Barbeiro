# 💈 Mestre Barbeiro

Website institucional desenvolvido para uma barbearia fictícia, com foco em apresentar os serviços, identidade visual, localização e formas de contato de maneira moderna e profissional.

O projeto foi criado com o objetivo de simular um site real para uma empresa, priorizando **design responsivo, experiência do usuário e apresentação visual dos serviços**.

---

## 📸 Sobre o projeto

O **Mestre Barbeiro** é uma landing page responsiva desenvolvida para representar uma barbearia moderna.

A proposta é oferecer ao cliente uma experiência simples e agradável, permitindo que ele conheça a barbearia, visualize os serviços disponíveis, consulte informações de localização e entre em contato.

---

## ✨ Funcionalidades

* 🏠 Página inicial com apresentação da barbearia
* 💈 Seção de serviços
* 📍 Localização integrada ao Google Maps
* ⭐ Sistema visual de avaliação por estrelas
* 💬 Área para envio de feedback
* 📱 Design totalmente responsivo
* 📞 Área de contato
* 📲 Link direto para WhatsApp
* 🖼️ Identidade visual personalizada
* ✨ Animações e efeitos de interação
* 🧭 Navegação entre as seções do site

---

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

* **HTML5** — estrutura das páginas
* **CSS3** — estilização, responsividade e animações
* **JavaScript** — interações e funcionalidades
* **Font Awesome** — ícones
* **Google Maps** — localização da barbearia
* **Google Fonts** — tipografia

---

## 🎨 Identidade visual

A identidade visual do projeto foi construída utilizando uma estética:

* Preto e grafite como base
* Tons claros para textos
* Detalhes sutis em cobre e marrom
* Efeitos de transparência
* Glassmorphism
* Gradientes discretos
* Sombras e iluminação suave

A intenção é transmitir uma sensação de **sofisticação, confiança e profissionalismo**, sem deixar o layout visualmente pesado.

---

## 📱 Responsividade

O site foi desenvolvido para funcionar em diferentes tamanhos de tela:

* 🖥️ Desktop
* 💻 Notebook
* 📱 Smartphones
* 📲 Tablets

O layout se adapta automaticamente para proporcionar uma boa experiência de navegação independentemente do dispositivo utilizado.

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/mestre-barbeiro.git
```

### 2. Entre na pasta

```bash
cd mestre-barbeiro
```

### 3. Abra o projeto

Abra o arquivo `index.html` diretamente no navegador ou utilize uma extensão como **Live Server** no Visual Studio Code.
